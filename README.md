# POWERDRIVE HANYANG 🏓
> 한양대학교 ERICA 탁구 동아리 '탁우회' 웹사이트 · https://powerdrive-hanyang.vercel.app

로그인 없이 링크 하나로 씁니다. 부원 명단(이름·부수·라켓)은 구글 시트 `26-2 탁우회 부수표`의 `시트2`에서 읽고, 경기 기록과 토너먼트도 구글 시트에 저장합니다.

## 사용 방법

### 부수 검색 `/search`
* 이름을 치면 바로 결과가 바뀝니다. `ㅎㄱㄷ`처럼 초성만 쳐도 찾습니다.
* 부수 버튼을 눌러 걸러 보고, 결과 주소를 그대로 공유할 수 있습니다.

### 통계 `/stats`
* 부수별 인원 막대를 누르면 그 부수 명단으로 갑니다.
* 아래에 부수별로 묶은 전체 명단이 있습니다. 부수가 없는 부원은 '미지정'에 모입니다.
* 시트에 라켓 정보가 있으면 쉐이크·펜홀더 구성도 함께 보입니다(없으면 라켓 관련 화면은 숨겨집니다).

### 경기 점수판 `/scoreboard`
1. 11점(번외 21점)과 3판 2선·5판 3선을 고르고, 두 선수를 이름(초성 가능)으로 고릅니다. 상대 전적이 보입니다.
2. 경기를 시작하면 전체화면이 되고, 화면 양쪽을 눌러 점수를 올립니다. 듀스와 서브 교대는 자동이고, 되돌리기·서브 변경·자리 교대가 있습니다.
3. 끝나면 **전적에 저장**을 눌러 `경기기록` 시트에 남깁니다.

### 토너먼트 `/league`
**운영진**
1. **토너먼트 개설**에서 이름, 점수, 예선 여부, 5판 3선으로 바꿀 라운드, 배치 방식(무작위·부수 순), 그룹 기준을 정합니다. 참가 코드와 관리자 코드(각 6자리)가 나옵니다.
2. 참가 코드를 알려 주거나 운영 화면의 **참가 QR 코드**를 보여 줍니다. 명단에서 골라 직접 넣을 수도 있습니다.
3. **대진표 만들기**를 누르면 부수로 그룹(기본 상위부 4부 이하 · 중위부 5\~7부 · 하위부 8부 이상)을 나눠 그룹마다 대진표가 생깁니다. 이름을 끌어 놓아 고칩니다(폰은 꾹 누른 뒤). 이때 들어온 사람은 빈 자리에 자동으로 들어갑니다.
4. **토너먼트 시작**을 누르면 참가 접수가 끝나고 참가자에게 대진표가 보입니다.
5. 결과를 확정하면 승자가 다음 경기로 올라가고, 모든 그룹의 우승자가 정해지면 끝납니다. 3·4위전은 그룹마다 켤 수 있습니다.

**예선을 고른 경우**: 그룹마다 3명씩 조를 짜 리그전(3판 2선)을 하고 조 1·2위가 본선 토너먼트(모두 5판 3선)에 오릅니다. 3명으로 나누고 남는 2명은 경기로 1·2위를 정한 뒤 둘 다 본선에, 1명은 본선에 바로 오릅니다. 순위는 승수 → 동률인 사람끼리의 게임 비율 → 점수 비율로 정하고, 그래도 같으면 운영진이 **순위 정하기**로 정합니다. 본선에서는 조 1위가 다른 조 2위와 첫 경기를 합니다. 화면의 **예선/본선** 탭으로 조 순위표와 본선 대진을 바꿔 봅니다.

다른 기기에서 운영하려면 **열려 있는 토너먼트**에서 그 카드의 **운영**을 누르고 관리자 코드를 넣습니다. 토너먼트를 지우려면 운영 화면 맨 아래의 **토너먼트 삭제**를 누르고 관리자 코드를 한 번 더 넣습니다(되돌릴 수 없고, 전적에 저장된 경기 기록은 남습니다).

**참가자**
1. **열려 있는 토너먼트**에서 카드의 **참가하기**를 누르고 이름 → 참가 코드 순서로 넣습니다. QR을 찍으면 코드가 채워져 있습니다.
2. 맨 위 **내 정보**에 그룹·다음 경기·순위가 보입니다. **점수판으로 경기**로 경기하거나, 끝난 뒤 **결과 보내기**를 누르면 운영진이 확정합니다. 결과는 '김도윤 2:1 승'처럼 승자와 세트 스코어를 한 번에 고르면 되고(모르면 '승자만'), 게임마다의 점수는 선택입니다.
3. 폰을 바꿨거나 연결이 끊겼으면 같은 방법으로 다시 들어오면 이 기기로 다시 연결됩니다(예전 기기는 끊깁니다).

참가하지 않고 보기만 하려면 카드의 **대진표 보기**를 누릅니다. 구조와 결정 사항은 [`docs/league-handoff.md`](docs/league-handoff.md)에 있습니다.

### 부원 명단 올리기 (운영진)
`python upload_members.py`로 창을 열어 CSV(열: 이름·부수·라켓)를 고르거나, `python upload_members.py 명단.csv`로 바로 올립니다. 기본은 덮어쓰기이고 `--mode append`로 뒤에 붙입니다.

## 배포

Vercel에 연결되어 있어 main에 푸시하면 실서비스에 자동 배포됩니다(리전 서울 `icn1`). 다른 브랜치는 프리뷰 주소로 배포되는데, 프리뷰도 실서비스와 같은 시트를 쓰므로 시험으로 만든 데이터는 바로 지웁니다. 로컬 실행은 `pip install -r requirements.txt` 뒤 `python app.py`(포트 5001)입니다.

| 환경변수 | 내용 | 기본값 |
| --- | --- | --- |
| `GOOGLE_CREDENTIALS_JSON` | 서비스 계정 키 JSON 본문. 로컬에서는 프로젝트 루트의 `credentials.json`이나 `GOOGLE_APPLICATION_CREDENTIALS`(키 파일 경로)를 씁니다 | |
| `SHEET_ID` | 부수표 파일 ID. 학기가 바뀌면 이 값만 바꿉니다(비우면 `SHEET_NAME` 제목으로 찾음) | `26-2 탁우회 부수표` |
| `MEMBER_WORKSHEET` | 부수표 안의 표 형태 시트 | `시트2` |
| `RECORDS_SHEET_NAME` | 경기 기록 파일. 서비스 계정에 편집 권한이 있어야 합니다 | `탁우회_명단` |
| `LEAGUE_SHEET_NAME` / `LEAGUE_SHEET_ID` | 토너먼트 파일. 서비스 계정에 편집자로 공유하면 처음 개설할 때 시트가 자동으로 만들어집니다 | `탁우회 토너먼트` |
| `SHEET_CACHE_TTL` | 시트 캐시 시간(초) | `60` |
