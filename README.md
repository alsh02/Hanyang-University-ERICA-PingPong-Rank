# POWERDRIVE HANYANG 🏓
> **한양대학교 ERICA 탁구 동아리 '탁우회' 웹사이트 (부수 검색 · 전력 대시보드 · 경기 점수판)**

POWERDRIVE HANYANG은 대학 탁구 동아리 운영진과 부원들이 모바일 및 웹 환경에서 부원들의 이름, 부수, 사용 라켓(전형) 정보를 실시간으로 조회하고 동아리 전체의 통계 현황을 손쉽게 모니터링할 수 있도록 돕는 독립형 웹 서비스입니다.

---

## ✨ 주요 기능 및 특징
1. **메인 허브 (`/`)**: 동아리 현황(등록 인원·부수 수·전형 구성)과 최근 경기를 보여주고, 부원 검색·통계 대시보드·경기 점수판으로 이동합니다.
2. **로그인 없는 1초 부수 검색 (`/search`)**: 동아리원들이 가입 및 로그인 단계 없이 링크 하나로 편리하게 부원을 검색합니다.
   * **즉시 검색**: 입력하는 동안 페이지 이동 없이 결과가 바로 바뀌며, `ㅎㄱㄷ`처럼 초성만으로도 이름을 찾을 수 있습니다.
   * **원탭 필터**: 부수·라켓 칩을 눌러 바로 조회하고, 검색 결과 주소를 그대로 공유할 수 있습니다.
3. **실시간 통계 대시보드**: 
   * **부수 분포도**: collections.Counter 집계를 통해 각 부수별 인원을 막대 그래프로 시각화하고, 막대마다 쉐이크/펜홀더 구성을 함께 보여줍니다. 막대를 누르면 해당 부수 명단으로 이동합니다.
   * **라켓 구성비**: 쉐이크핸드와 펜홀더 비율 및 전형별 평균 부수를 직관적인 카드로 비교 분석합니다.
   * **그룹화 목록**: 부수 오름차순 및 이름순 정렬을 제공하여 대회 대진표 및 경기 매칭 시 운영 리소스를 대폭 줄여줍니다. 부수를 입력하지 않은 부원은 '미지정' 그룹으로 모아 누락 없이 보여줍니다.
4. **비용 제로 데이터 소스**: 구글 스프레드시트(Google Sheets API)를 데이터베이스 소스로 사용하여 유지보수 비용을 0원으로 실현했습니다.
   * 시트 데이터는 60초간 캐시(환경변수 `SHEET_CACHE_TTL`로 조정)하여 구글 API 호출 한도를 넘지 않으며, 연동 오류가 나도 마지막으로 불러온 명단을 계속 보여줍니다.
5. **데이터 정규화 (Normalization) 전처리**:
   * 시트 입력 오타(예: `세이크`, `셰이크`, `팬홀더`, `3`, `0` 등)를 백엔드에서 자동으로 감지해 `쉐이크`, `펜홀더`, `3부`, `0부` 등으로 실시간 보정 정제하여 데이터의 신뢰성을 보장합니다.
6. **경기 점수판 (`/scoreboard`)**:
   * 경기를 시작하면 자동으로 전체화면이 되고(설정 화면으로 돌아오면 해제), 화면 양쪽을 눌러 점수를 올립니다. 11점 경기와 번외 21점 경기를 모두 지원하며, 듀스와 서브 교대(11점은 2점마다, 21점은 5점마다, 듀스 후에는 1점마다)를 규칙대로 처리하고 서브 차례인 선수 쪽 배경을 강조합니다.
   * 3판 2선 / 5판 3선을 고르면 가운데에 게임 스코어가 표시되고, 되돌리기·서브 변경·자리 교대를 지원합니다.
   * 선수는 이름을 입력해 고릅니다. `ㅎㄱㅁ`처럼 초성만 쳐도 아래에 후보가 뜨고, 누르면 선택됩니다. 두 선수가 정해지면 상대 전적이 표시되고, 끝난 경기는 구글 시트의 `경기기록` 시트에 누적됩니다.
7. **회원 명단 일괄 업로드 매니저 (GUI & CLI 듀얼 지원)**:
   * 운영진을 위한 회원 데이터 일괄 등록 도구(`upload_members.py`)가 내장되어 있으며, GUI(데스크톱 창) 및 CLI 모드를 모두 지원합니다.

## 🚀 배포

* **Vercel**: 저장소를 연결하면 `app.py`를 자동으로 인식합니다. 서버가 잠들지 않아 첫 접속이 빠르며, 리전은 서울(`icn1`)로 지정되어 있습니다.
* **Render**: Build Command `pip install -r requirements.txt` / Start Command `gunicorn app:app`.
* 구글 시트 연결은 아래 환경변수로 설정합니다.
  * `GOOGLE_CREDENTIALS_JSON`: 서비스 계정 키 JSON **본문** (Vercel처럼 키 파일을 둘 수 없는 환경용)
  * `GOOGLE_APPLICATION_CREDENTIALS`: 키 파일 경로 (Render의 Secret Files 등). 로컬에서는 프로젝트 루트의 `credentials.json`을 자동으로 찾습니다.
  * `SHEET_CACHE_TTL`: 시트 캐시 유지 시간(초), 기본값 60
